# Design

## Visual Direction

Modern digital museum.

Characteristics:

- Dark architectural environment
- Gallery-style lighting
- Clean museum walls
- Minimal futuristic accents
- Blue/cyan digital lighting
- Warm spotlight for exhibits
- Large open spaces
- Minimal floating UI

## Museum Atmosphere

The museum should feel:

- premium
- quiet
- cinematic
- modern
- immersive
- professional

Avoid:

- excessive cyberpunk visuals
- game-like HUD
- overly complex controls
- visual clutter

## Exhibits

Each project is represented as a museum exhibit.

An exhibit may contain:

- project title
- project year
- project category
- 3D visual or screen
- short description
- tech stack
- interaction prompt

When an exhibit is selected:

- camera focuses on the exhibit
- detailed project UI appears
- visitor can inspect the project
