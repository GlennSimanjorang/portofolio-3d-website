# Glenn Digital Museum

## Goal

Build an interactive 3D digital museum that showcases my projects,
skills, experience, and journey as a software developer.

## Core Concept

The portfolio is presented as a virtual museum.

Each project is represented as an exhibit inside the museum.

Visitors explore the museum to discover:

- Projects
- Skills
- Experience
- Achievements
- About Me
- Contact Information

## Target Experience

The experience should feel like visiting a modern digital museum,
not playing a game.

Navigation must remain simple and intuitive.

## Main Areas

1. Entrance
2. Lobby
3. Project Exhibition Hall
4. Skills Gallery
5. Experience Gallery
6. About Me Installation
7. Contact / Exit Hall
