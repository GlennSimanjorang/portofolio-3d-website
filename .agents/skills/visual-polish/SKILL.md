# Visual Polish

Use for a requested visual refinement pass. Read `docs/DESIGN.md`, `docs/DESIGN_SYSTEM.md`, and `docs/EXPERIENCE.md`; inspect the current scene and UI before editing.

- Refine materials and lighting as a hierarchy: architecture first, exhibits second, interaction accents last.
- Frame exhibits for comfortable reading and keep the selected project clear beside its detail view.
- Keep motion cinematic and restrained; preserve camera control, reduced-motion needs, and usability.
- Avoid excessive neon, cyberpunk effects, glassmorphism, and decorative post-processing.
- Check desktop and mobile views, contrast, performance cost, and browser console when possible. Change only the requested visual scope.
