# Responsive Review

Use for a requested responsive audit or change. Read `docs/DESIGN.md`, `docs/DESIGN_SYSTEM.md`, and `docs/EXPERIENCE.md`; inspect the relevant CSS and rendered viewports when possible.

- Check viewport fit, horizontal overflow, text readability, image scaling, and safe areas.
- Verify that project selection, close actions, scrolling, and keyboard or touch targets remain reachable.
- Preserve the desktop museum experience while checking the compact scene, project picker, and detail sheet.
- Use a mobile fallback where spatial controls become too small; do not force desktop navigation onto mobile.
- Report tested viewport sizes, observations, and any browser verification still needed. Implement only requested changes.
