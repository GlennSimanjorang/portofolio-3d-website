# UI and UX Review

Use for a requested visual or usability audit. Read `docs/DESIGN.md`, `docs/DESIGN_SYSTEM.md`, and `docs/EXPERIENCE.md`; inspect the relevant UI and, when possible, the rendered desktop experience.

- Review hierarchy, typography, spacing, consistency, and interaction clarity.
- Check readable contrast, focus visibility, keyboard access, labels, and close or return actions.
- Evaluate whether exhibit content and detail views feel editorial and museum-like rather than like generic dashboard cards.
- Separate observed problems from design preferences. Cite the screen, viewport, and component for each finding.
- Prioritize findings by visitor impact and suggest focused changes. Do not implement changes unless requested.
